# Gaurav Singh Portfolio

A responsive personal portfolio website for Gaurav Singh, a Computer Science student and software engineer.

## Contents

- About and technical skills
- Selected projects
- Contact links
- Light and dark theme support

## Run locally

This is a standalone HTML site with no build step or dependencies.

1. Clone the repository.
2. Open `Gaurav_Singh_v4.html` in a modern web browser.

Alternatively, serve the directory using any static web server.
